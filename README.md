# Прогнозирование риска отсева студентов (Student Dropout Prediction)

Модель машинного обучения для раннего выявления студентов с высоким риском отчисления на основе данных образовательной аналитики. Проект направлен на то, чтобы преподаватели и администрация могли заранее видеть, кому из студентов может понадобиться дополнительная поддержка.

## Задача

Бинарная классификация: предсказать, отчислится ли студент (`Withdrawn`) на основе демографических данных и данных об учебной активности.

## Данные

Использован датасет **Open University Learning Analytics Dataset (OULAD)** — открытые данные о студентах онлайн-образования, включающие:
- Демографические характеристики (пол, регион, возраст, уровень предыдущего образования)
- Социально-экономические индикаторы (indices of multiple deprivation)
- Историю предыдущих попыток обучения и количество зачётных единиц

Источник: [Open University Learning Analytics Dataset](https://analyse.kmi.open.ac.uk/open-dataset)

## Методология

1. **Предобработка данных**: обработка пропущенных значений, кодирование категориальных признаков (one-hot encoding)
2. **Проблема дисбаланса классов**: доля отчисленных студентов значительно меньше доли завершивших курс, что потребовало применения `class_weight='balanced'`
3. **Модели**: сравнение логистической регрессии и Random Forest, каждая — в baseline и сбалансированной версии
4. **Оценка**: precision, recall, f1-score с акцентом на recall для класса "отсев" — в задачах раннего предупреждения пропустить реального кандидата на отчисление дороже, чем ложно отметить студента без риска

## Результаты

| Модель | Precision (отсев) | Recall (отсев) | F1-score (отсев) | Accuracy |
|---|---|---|---|---|
| Логистическая регрессия (baseline) | 0.56 | 0.17 | 0.26 | 0.71 |
| Random Forest (baseline) | — | 0.30 | 0.35 | — |
| **Логистическая регрессия (balanced)** | **0.41** | **0.61** | **0.49** | **0.61** |
| **Random Forest (balanced)** | **0.41** | **0.60** | **0.48** | **0.62** |

**Ключевой вывод**: балансировка классов (`class_weight='balanced'`) даёт кратный прирост recall (с 0.17–0.30 до ~0.60) для обеих моделей. При этом тип алгоритма (линейный vs ансамблевый) в данной задаче оказался менее значим, чем сама работа с дисбалансом классов — обе сбалансированные модели показали сопоставимые результаты.

## Значимые признаки

Анализ важности признаков (Random Forest feature importance и коэффициенты логистической регрессии) показал, что наибольший вклад в предсказание риска отсева вносят:
- количество предыдущих попыток обучения
- количество зачётных единиц (studied credits)
- социально-экономический индекс региона (imd_band)
