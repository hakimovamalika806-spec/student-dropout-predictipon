# student-dropout-predictipon
Прогнозирование риска отсева студентов
Модель машинного обучения для раннего выявления студентов с высоким рисков отчисления на основе данных образовательной аналитики. проект направлен на то чтобы преподаватели и администрация могли заранее видеть, кому из студентов может понадобиться дополнительная поддержка. 
Задача.
Бинарная классификация: предсказать, отчислиться ли студент(WithDrawn) на основе демографических данных и данных об учебной активности.
Данные.
Использован датасет Open University Learning Analytics. Dataset (OULAD) — открытые данные о студентах онлайн-образования, включающие:
 - Демографические характеристики (пол, регион,возраст, уровень предыдущего образования).
 - Социально-экономические индикаторы (indices of multiple deprivation).
 - Историю предыдущих попыток обучения и количество зачётных единиц.
